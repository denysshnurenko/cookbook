# daily-brief

Щоденний бриф до стендапу, який агент збирає сам: що я зробив, що зламалось, що заплановано
і **на що мені досі не відповіли** — з GitHub, Slack і трекера задач. Результат — Slack Canvas
з деталями плюс коротке повідомлення в канал, де кожен рядок веде вглиб канваса.

Це знімок того, як зроблено в мене. Не універсальний застосунок — рецепт: беріть цілком або
розберіть на частини.

## Навіщо

Стендап питає «що з вчорашнього дня». Відповідь розкидана по трьох місцях, і найдорожче
губиться не зроблене, а **питання, яке тобі поставили і яке ти не помітив**. Бриф збирає все
докупи і окремою секцією показує згадки, на які ти не відповів по суті.

## Що дає

| секція | що туди йде |
|---|---|
| ✅ Зроблено | змерджені PR, задачі в завершеному статусі, зелені деплої, дороблені ревʼю |
| ⚠️ Блокери | впалі деплої, «блокер»/«терміново» в Slack, очікування на інших, статуси Fix Needed |
| 📨 Висить на мені | згадки, де тебе тегнули, а ти не відповів **по суті** до кінця вікна |
| 📅 Плани | відкриті PR, призначені незакриті задачі, обіцянки в Slack, TODO |
| 📁 Інше | дрібний адмін |

## Що потрібно

- **Claude Code** — рецепт ставиться як skill
- `gh` (авторизований), `jq`, `python3`
- **Slack MCP** — читання повідомлень і створення канваса
- **MCP трекера задач** (у мене — DOTT) — необовʼязково: без нього бриф збереться з GitHub + Slack
- **Slack-бот з `chat:write`** — щоб бриф тебе сповіщав, див. нижче

## Встановлення

```bash
mkdir -p ~/.claude/skills/daily-brief/helpers
cp AGENTS.md            ~/.claude/skills/daily-brief/SKILL.md
cp collect-github.sh crossref.py post-as-bot.py ~/.claude/skills/daily-brief/helpers/
cp config.example.json  ~/.claude/skills/daily-brief/config.json
```

Далі відредагуй `config.json`: канал і його id, час стендапу, воркспейс Slack, хост трекера і
свою робочу пошту (нею скіл знаходить твій id у трекері — whoami там зазвичай немає).

### Токен бота

Бриф постить **не від твого імені**, і це не дрібниця: **Slack не шле сповіщення про твої
власні повідомлення**. Якщо канал брифу — це канал, де ти єдиний учасник, бриф від себе
прилітає вже прочитаним. Саме так брифи й губляться.

Створи Slack-апку зі скоупом `chat:write`, встанови у воркспейс, поклади bot token у Keychain:

```bash
security add-generic-password -a "$USER" -s slack-daily-brief-bot-token -w '<bot token>'
```

Канвас і далі створюється твоїм користувацьким токеном — ботом іде лише фінальне повідомлення.

## Користування

```
/daily-brief                          # з минулого стендапу до сьогоднішнього
/daily-brief --days=7                 # за тиждень
/daily-brief --date=2026-08-24        # конкретний день
/daily-brief --dry-run                # показати, нічого не постити
```

Дефолтне вікно — **від учорашнього стендапу до сьогоднішнього**, тож у нього потрапляє і
вечірня робота, і сьогоднішня ранкова до зустрічі. У понеділок вікно тягнеться з пʼятниці.

Повертаєшся після кількох днів відсутності — став `--from`/`--to` руками. Скіл навмисно не
вгадує пропуски.

## Чесно про обмеження

**Дані з трекера — наближення, а не факт.** MCP трекера зазвичай не має ні журналу активності
по користувачу, ні серверних фільтрів «хто і коли змінив». Тому секція трекера показує
«призначені мені задачі, які рухались у вікні», а не «що саме зробив я»: будь-яка правка
будь-ким піднімає `updatedAt`. Джерело правди про зроблене — GitHub і Slack; трекер відповідає
на питання «в якому стані моя дошка».

**Пошук згадок бачить не все.** Ловляться лише прямі `@you`. `@channel`, `@here` і згадки через
user-group у пошук не потрапляють.

**Відповідь після cutoff.** Якщо ти відповів наступного ранку, для *цього* вікна згадка все
одно рахується невідповіданою — бриф позначає «відповів одразу після cutoff», щоб вона не
спливла завтра ще раз як проігнорована.

**Deep links у канвас** спрацьовують лише на «холодне» відкриття. Якщо канвас уже відкритий,
клік нічого не прокрутить — тому в повідомленні є підказка закрити його спершу.

**Дві системи id.** `crossref.py` навмисно матчить і номери задач поточного трекера, і старі
10-значні id — під час переїзду між трекерами старі коміти ще місяцями вказують на стару
систему. Те, що лежить у різних просторах id, не зійдеться саме собою: рецепт показує розрив,
а не підганяє його.

| `AGENTS.md` | сам скіл — процедура для агента. Ставиться як `SKILL.md` |
