# cookbooks

Практичні гайди по моєму dev-тулінгу — кожен у парі: `README.md` (для людини) +
`AGENTS.md` (для AI-агента, згодовується як skill або контекст).

- [worktree/](worktree/) — git worktree на кожну гілку з ізольованим оточенням:
  створення (`worktree new`) і архівація (`worktree archive`).

Скрипти, на які посилаються гайди, живуть у моєму приватному harness-репо — якщо
треба, попроси.
